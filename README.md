# 1970s Retro Arcade Games

This folder is a static website for GitHub Pages. It uses only HTML, CSS, and JavaScript, so it can run on a school Chromebook without installing anything.

Included games:

- Pong
- Space Invaders
- Asteroids
- Galaxian
- Breakout

## Play locally

Open `index.html` in a browser.

## Publish on GitHub Pages

1. Upload this project to a GitHub repository.
2. Open the repository settings.
3. Go to Pages.
4. Set the source to the main branch and the `/docs` folder.
5. Save, then open the GitHub Pages link that GitHub gives you.
